        Getting started

        1. Choose a graph. Use the graph finder or choose a category on the Welcome page. Select an example to explore a complete editable workspace.
        2. Add your data. Paste a table into the data grid, or use Open or Import for a supported file. The first row can contain column titles.
        3. Set up the figure. Use the General, Data, and Format toolbar tabs to choose the graph, prepare data, and adjust its appearance. Graph-specific settings are available beside the figure.
        4. Save or export. Save a .graph file to reopen the workspace later. Export a figure as SVG or PNG when you are ready to use it elsewhere.

        Common questions

        Which files can I open?

        Graphitix workspaces (.graph), Prism data files (.prism and .pzfx), CSV, TSV, TXT, Excel (.xls and .xlsx), and ODS files are supported.

        How do I save and reopen my work?

        Choose Save or Save As to download a .graph workspace. Open that file later to restore its tabs, data, graph settings, and saved analysis state.

        Does Graphitix upload my data?

        Graphitix runs plotting and most analyses in your browser. Optional GO, STRING, and UniProt lookups contact those services when you use them. Feedback links open GitHub or your email app; Graphitix does not automatically send or attach your graph or data.

        How can I report a problem or suggest an improvement?

        Open Send feedback to file an issue in the Graphitix GitHub repository or email me directly.

        About Graphitix

        Graphitix is a browser-based application for creating publication-ready scientific figures and running statistical analyses. It combines editable data tables, graph controls, analysis tools, and reusable multi-tab workspaces.

        The application is free and open source under the MIT License.

        Found a bug, have a question, or have an idea for improving Graphitix? You can file an issue in the Graphitix GitHub repository or email me directly.
