Refactor by extending the shared builder, or extracting its genuinely common numeric-section primitive, with explicit options for labels, units, ranges, source/mirror inputs, insertion position, interaction callbacks, and undo policy. Migrate only semantically equivalent sections; keep Symbol's feature-specific state/undo adapter explicit if it cannot use the full helper without behavior changes. Before deleting any local builder, verify all call sites with repository search. Acceptance: one shared construction path for equivalent numeric color-picker sections; identical wheel, validation, formatting, mirroring, commit/cancel, cleanup, accessibility, and owner-binding contracts across migrated toolbars; no change to canonical/session/payload precision; targeted Jest coverage for each migrated variant plus representative Chromium checks for popup lifecycle, wheel commit/cancel, undo, and same-component tab isolation. This is maintainability and behavioral-drift debt, not the confirmed root cause of the original Line screenshot.
