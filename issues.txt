[open][P3][2026-08-21] Shared p-value formatting silently clamps finite inputs outside the valid probability range `[0, 1]` before presentation. A negative upstream result is therefore displayed as an extreme valid probability instead of exposing the statistical defect, while values above one become `1`. Define one invalid-probability reporting contract, return an explicit unavailable/error state for out-of-range inputs, and add shared/component tests without weakening the separate floating-point underflow threshold behavior for a legitimate zero result.
