## 1. Definition of professional grade

- Valid source and runtime markup; meaningful names and relationships; keyboard access, visible focus, predictable dialogs and menus.
- A documented WCAG 2.2 AA acceptance target for application controls/content. Automated checks alone do not establish conformance; record manual and assistive-technology evidence and unresolved exceptions.
- Readable, operable controls at narrow widths, browser zoom and enlarged text. Confine intentional scrolling to tables/plots that require two-dimensional presentation.
- A coherent visual system with explicit tokens, style/state ownership, predictable cascade, and supported browser fallbacks.
- Reproducible validation that prevents new debt, followed by retirement of the baseline. A large accepted baseline is an intermediate stage, never the finished result.
- Preservation of tab isolation, saved graph dimensions/settings, reopen behavior, export geometry, and approved compact desktop presentation.

Use [WCAG 2.2 Understanding](https://www.w3.org/WAI/WCAG22/Understanding/) for acceptance criteria and the [APG tabs](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/), [combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) and [modal dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) patterns for custom interactions. APG guides implementation; it does not certify the application.

## 3. Architectural decision and boundaries

Confirmed label/focus problems affect shared patterns and multiple components. A welcome-only patch cannot satisfy this goal. The necessary refactor is bounded: repair shared presentation contracts/builders, then migrate verified consumers in small batches. Do not introduce a framework, rebuild sessions, or infer names from arbitrary neighboring text after rendering.

| Boundary | Sources | Authority/rule |
| --- | --- | --- |
| Tokens/cascade | `css/style.css`, AG Grid styles loaded by `index.html`, runtime styles | CSS owns presentation. Shared grid row height is a CSS token consumed by the table runtime for matching geometry. Account for deferred vendor CSS arrival, conditional rules and inline geometry before changing precedence. |
| Static controls | `index.html` | Associated labels, fieldsets/legends, descriptive hints/errors; preserve control IDs required by consumers. |
| Dynamic controls | `js/shared/workspaceToolbar.js`, `fontControls.js`, `axisControls.js`, `symbolToolbar.js`, `gridControls.js`, `significanceControls.js`, `statsInference.js`, `dataViews.js`, `notes.js`, `hot.js`, `agGridAdapter.js` | Builders emit valid named controls/state semantics. Owner-varying IDs are unique; relationships refresh with projection. |
| Menus/portals | `toolbarOverflow.js`, `menuKeyboard.js`, `menuPosition.js`, `colorPicker.js`, `formControls.js`, tab context menus | Correct focus, close/return behavior, clipping, stacking and positioning; retain native select fallback. |
| Tabs/search | `js/main/tabs.js`, `js/main/tabs/render.js`, `js/main/bootstrap.js` | Existing workspace/session APIs remain canonical; DOM/ARIA is a projection. |
| Dialogs | `js/shared/modalLifecycle.js`, `index.html`, `js/main.js`, tabs prompt modules, `sessionActions.js`, `styleSync.js` | The shared manager owns stack/focus/inert/scroll behavior; each flow declares initial focus and Escape policy. `aria-modal` alone implements none of these. |
| Layout/graphs | `componentLayout.js`, `resizer.js`, `graphSizing.js`, `plot3d.js` | Responsive controls cannot overwrite canonical graph dimensions, legend reserves, stored ratios or export layout. |
| Validation | `package.json`, `scripts/run-test-lane.cjs`, `.github/workflows/`, `test-support/scenarioCatalog.js` | Coherent gate/report/scenario contract, explicit coverage and omissions. |

Dialog behavior belongs in `Shared.modalLifecycle`; extend that contract and its shared tests instead of adding per-prompt traps. If another repair requires changes to durable state, root ownership, archive schema, or the shared graph-layout model, stop that slice and report the larger refactor. Deduplicate confirmed unrelated findings in `issues.txt`. Never use DOM cleanup or capture-time synchronization as the repair.
